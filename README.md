# Part A — HTML Assignment

This assignment demonstrates the use of semantic and accessible HTML to create two connected web pages.

## Pages

### `index.html`

The first assignment page containing my personal information and profile.

### `form.html`

An account creation/application form inspired by the ALT School application page.

The two pages are connected using global navigation at the top of each page.

## Navigation

Both pages contain links that allow users to move between:

* Home (`index.html`)
* Application Form (`form.html`)

## HTML Concepts Used

* Semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`
* Accessible form labels and form controls
* Form elements such as `<input>`, `<fieldset>`, `<legend>`, and `<button>`
* Internal page navigation
* Back-to-top navigation
* `<dialog>` for modal holding student details
* `<address>` for location information

## Styling

This assignment was completed **without CSS**, as required by the assignment instructions.

The focus is therefore on the structure, semantics, accessibility, and proper use of HTML.
